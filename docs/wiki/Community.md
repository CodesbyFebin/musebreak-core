# Build the evidence with us

MeTaBoss welcomes contributors interested in business integrity, useful assistants and clear trust boundaries. We do not need every contribution to add a new framework or another named agent.

## Useful first work

Reproduce the synthetic invoice example. Explain a confusing error message. Improve accessible review UI. Add a negative test where a receipt or approval could be substituted. Document exactly which model executed a controlled request. Propose a provider adapter with a bounded effect and independent observation source.

Read [CONTRIBUTING.md](../../CONTRIBUTING.md) and [AGENTS.md](../../AGENTS.md) before editing. Keep changes focused and record actual validation. Use synthetic data, preserve license attribution, and keep private credentials out of issues and screenshots. A finite test set supports a specific claim, not a 100/100 security score.

## Share responsibly

Link the source, explain prototype status and include limitations. Genuine reproduction reports and independent technical discussion are welcome. Fake testimonials, star schemes, mass unsolicited promotion and unsupported official affiliations are not. Maintainer review depends on capacity; no response SLA or guaranteed merge is promised.
