# Questions about MeTaBoss

## Is the repository public?

Yes: [CodesbyFebin/musebreak-core](https://github.com/CodesbyFebin/musebreak-core). A model without browsing or a recent index may not recognize it. Share an exact public URL and ask whether it actually retrieved the content; do not share credentials.

## What can be verified?

The new receipt checker verifies local invoice issuance, movements and event consistency against a pinned public key and supplied database. It does not establish payment, delivery, latest history or an uncompromised issuer. See [security](Security.md).

## Is the invoice code on main?

At this documentation revision it is proposed in [PR #1](https://github.com/CodesbyFebin/musebreak-core/pull/1). Follow [quick start](Quickstart.md) for the branch. Check live merge state rather than assuming documentation means a release.

## Is a Llama model Muse Spark?

No. Some historical tier names are aliases. Publish actual model IDs, provider/runtime and execution evidence. A local open-weight model is not automatically a hosted Meta model.

## Are robotics agents implemented?

No robot driver or ROS integration is delivered here. Robotics is a roadmap application of proposal, approval and independently observed outcome, with separate physical safety requirements. The hash-commitment MVP is not a safety proof.

## Can llms.txt force citations or awareness?

No. It is a retrieval guide. A model's training data, retrieval access and indexing policy remain outside this repository's control. Human-useful evidence and accessible pages matter more than hidden keywords.
